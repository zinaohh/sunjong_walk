# 개발 가이드 (요약)

순종워크를 이어서 개발할 때 지킬 최소한의 약속입니다. 레이어 분리와 화면별 뷰모델 구조를 쓰되, 이 앱 크기에 맞게 줄였습니다.

## 1. 지키는 원칙

- 핵심 기능에 필요한 것만 추가한다. 라이브러리를 새로 넣기 전에 없이 되는지 먼저 본다.
- 점수·연속 기록 숫자·순위·배지를 만들지 않는다. "그날 기록했다"는 표시만 남긴다.
- AI 사용 안 함, 말씀 추천 안 함. 성경 본문은 저장·표시하지 않고 위치만 기록한다.
- 서버·DB·로그인 없음. 기록은 기기 안에만 저장한다.
- 전역 상태 라이브러리를 쓰지 않는다. 상태는 화면마다 따로 가진다.

## 2. 지금은 넣지 않은 것

아래 상황이 실제로 생겼을 때만 추가합니다.

| 넣지 않은 것                 | 추가할 시점                                      |
| ---------------------------- | ------------------------------------------------ |
| DTO·mapper                   | 서버가 생겨 응답 모양과 앱 모델이 달라질 때      |
| use_case 계층                | 같은 로직이 뷰모델 2곳 이상에서 반복될 때        |
| 기능별 폴더 (`feature/〇〇`) | 화면이 10개 안팎으로 늘어 찾기 어려워질 때       |
| 전역 상태                    | 여러 화면이 같은 값(로그인 정보 등)을 함께 볼 때 |
| DI 라이브러리                | 저장소가 늘어 `data/index.ts` 한 파일로 안 될 때 |
| 코드 생성·다국어             | 지금은 계획 없음                                 |

## 3. 기능 하나를 추가하는 순서

예: "정하기" 화면에서 저장하기

1. **domain** - 필요한 값이 `model`에 있는지, 저장소 약속(`ObedienceRepository`)에 메서드가 있는지 확인한다.
2. **data** - 약속에 메서드를 추가했다면 `LocalStorageObedienceRepository`에 구현한다.
3. **contract.ts** - 화면에 새로 보일 값은 State에, 새로 일어나는 일은 Intent에 추가한다. (예: `submit`, `saved`)
4. **reducer.ts** - 각 Intent가 State를 어떻게 바꾸는지 쓴다. 저장소 호출은 여기서 하지 않는다.
5. **use〇〇ViewModel.ts** - 저장소 호출 같은 부수 효과를 여기서 하고, 끝나면 결과 Intent를 보낸다.
6. **〇〇Screen.tsx** - State를 그리고, 버튼·입력은 Intent를 보내기만 한다.

화면에서 저장소를 직접 부르지 않습니다. 레이어를 거꾸로 가져다 쓰면 `npm run lint`가 오류를 냅니다.

## 4. 다음에 구현할 순서 (제안)

1. 정하기: 입력값 저장 → 홈으로 이동
2. 이번 주(홈): 정한 순종과 오늘 기록 여부 보여주기
3. 오늘 체크: 선택 + 메모 저장 (같은 날 다시 하면 덮어쓰기)
4. 주간 돌아보기: 기록한 날 표시와 메모 목록

## 5. 브랜치·커밋·PR

- `main`은 항상 실행되는 상태로 둔다. 작업은 `feature/작업이름` 브랜치에서 하고 PR로 합친다.
- 커밋 메시지 앞에 종류를 붙인다: `feat`(기능) / `fix`(버그) / `docs`(문서) / `refactor`(구조 개선) / `test`(테스트) / `chore`(설정)
  - 예: `feat: 정하기 화면에서 이번 주 순종 저장`
- PR을 올리기 전에 아래 세 가지가 통과하는지 확인한다.

```bash
npm run lint
npm run format:check
npm run build
```

## 6. 아직 없는 것 (필요해질 때 추가)

- 테스트: 리듀서와 저장소부터 (순수 함수라 테스트하기 쉬움)
- PR 자동 검사(GitHub Actions)
- 오프라인 캐시(서비스 워커)
- 알림, 앱으로 감싸기(Capacitor), 앱스토어 출시 설정
- 로그인·서버 동기화: 넣게 되면 `src/data/`에 구현을 추가하고 `src/data/index.ts`만 바꾼다.
